# 界面行为

窗口分三栏：左边是工作区和会话列表，中间是主区，右边是可以收起的「答案解释」。主区一次只显示一页：会话页、日志页、技能页，或者连接页。日志页里再选 meta、messages、trace、context。

几条贯穿全局的规则：实时状态只出现在它自己的会话页上；输入框和草稿跟着页面走；切到别的会话查看，包括别的工作区的会话，不会打断正在执行的那一轮。重新加载页面会取消当时正在执行的轮次。

## 布局

- 会话页的标签显示会话标题，缺省是「会话」。标题文字右侧、同一组里，是「只看用户问题」图标，不和「日志」并排。图标只在会话标题选中时出现；点「日志」后它收起，再点标题才回来，过滤状态保留。技能页盖住主区时标题未选中，图标同样收起。图标默认绿白相间，点一下换成纯绿，对话里只留用户气泡；再点恢复全部消息。这个状态每个会话各记各的：切到别的会话，按那个会话自己的状态显示；新会话默认是全部消息。它只存在本次运行里，重启后都回到默认；会话缓存超过上限被挤掉后，那个会话也回到默认。纯绿时点某一条用户气泡，展开或收起这一轮的回复和工具，别的轮次不动，气泡本身留在原地。收起时这条问题自己的时间仍显示在气泡下面。刚发出的这一轮，以及正在生成的那一轮，会保持展开。点标题文字回到对话。打开会话后，标题组旁边是灰色的「日志」。点「日志」，按钮变黑，主区换成黑底日志页，页顶才是「meta」「messages (N)」「trace (N)」「context (N)」。再点会话标题回到对话，「日志」恢复灰色。新建会话页不显示标题组。
- 输入框是浮在主区底部的白卡片，只在会话页出现，不占一条横贯的底栏。对话区底部留出与卡片等高的空白，最后一行不会被挡住。
- 输入框平时收成一行（和解释栏里收起的那一行一样，半宽，只剩提示文字和发送按钮），点到它上面才展开。下面几种情况保持展开：会话还没开始（没有任何消息，包括新建会话页）；输入框有焦点；有草稿（文字、图片或视频还没发出）；正在等你回答（`ask_user`），或输入框被锁、被禁用（比如解释栏还没配置生文模型）。焦点离开、草稿又是空的，就收回去。主输入框和解释栏都是这个规则；浏览器页上的解释栏是同一个输入框，规则相同。
- 右侧「答案解释」用机器人图标打开，用向右滑入的图标关闭；打开时分走主区的一部分宽度。按钮的名称仍是「解释」和「收起」，栏目标题处也是同一个机器人图标。

## 工作区与会话

- 侧栏可以记多个工作区，点 + 是增加，不会换掉已有的那一条。后添加的工作区排在上面。工作区里的会话按最近一次写入消息的时间排，刚说过话的在上面。别的会话正在执行时也可以增加。刷新名单时先取回名字再换上，点一个会话的这段时间，名单不会先被清空。
- 点工作区名字或旁边的箭头，只展开或折叠它的会话，不换掉右侧正在看的页面。展开和折叠记在本机配置里，重启后保持。
- 工作区的「⋯」菜单有「打开文件夹」「重命名」「从列表中移除」。只有没有会话的工作区才能移除。重命名只改侧栏显示，不改目录名。
- 会话的「⋯」菜单可以就地改名和删除，删除前要确认。菜单挂在 `document.body` 上，避免被侧栏的滚动容器裁掉。
- 看过的会话把对话节点留在内存里，最多 8 份；正在执行或等你确认的那一份不会被挤掉。切回来时直接挂回这份节点，不读盘，所以你不在时到达的文字和工具行当时就画进它。删除会话时这份缓存一起丢掉，会话目录（消息、trace、context、任务、子代理和解释记录）整份删除；这一轮会被取消，后台子代理也会先停掉，见 [子代理、任务清单与完成通知](subagents-and-tasks.md#停止)。删的是当前正在看的会话时，回到新建会话页，「日志」和「只看用户问题」收起。删的是旁边另一条时，当前页不动。

## 发送、停止与并发限制

同时执行最多 5 个 runtime。上限和输入框的分工见 [路线图](roadmap.md#不同会话同时执行)。

- 正在执行的那一页，发送图标换成停止图标；点了之后是灰色的停止图标，直到这一轮真正结束。等你回答问题时，按钮仍是「回答」。停止只取消这一条。
- 主智能体在执行、又没在等你时，输入框收成一行，和解释栏里「简答」那一行同样大小，只剩提示文字和停止按钮；输入框上方不再另放一行阶段文字，阶段改写进提示文字里，省略号循环播放：「思考中」「思考中…」「思考中……」。阶段变了，文字跟着变，比如「执行工具……」「等待确认权限……」；系统设置为减少动画时，省略号不动。等你回答（`ask_user`）时输入框重新展开，上方显示「等你回答…」，按钮是「回答」，提示文字是「回答上面的问题…」。权限确认走权限卡，输入框仍是收起的。完成通知开出的续跑轮允许打字，输入框保持展开。这一轮结束后恢复展开。
- 一轮出错（比如模型接口返回 HTTP 429）时，对话里多一行红色的折叠行，样式和工具行一样，标题是「错误 · HTTP 429 · 接口返回的那句话」，请求编号不放进标题。最新的一条错误是展开的，红框里是「错误：」加完整原文；你发出下一条问题后它自动折起，点标题可以再展开。同一页上再出错，新的一条展开，旧的保持折叠。错误行不并进「N 个工具」，也不会写进会话记录，重新加载后不再显示。解释栏的错误同样处理。还没有配置模型、或当前模型缺 API Key / Base URL / Model 时，发送会被拦住，对话里写「还没有配置模型，请先在「模型」页添加」这类说明，草稿留在输入框里；连不上接口时标题写成「错误 · 连不上模型接口 · 地址」。
- 别的会话正在执行时，当前页照常打字、照常发送。阶段提示留在它自己那一页，不会带过来。
- 左侧每个还占着名额的会话标题前有一枚转圈，父轮次结束后，只要后台子代理还没结束，圈就继续转。工作区被折叠、里面却有这样的会话时，转圈改标在工作区名字前。停在权限确认或「等你回答」、而你正看着别处时，转圈换成不转动的等待标记。这一轮已经结束时，输入框可以再发；停止只取消还在这一轮里的工作，不会取消已经交给后台的子代理。
- 输入框缩小后不显示模型选择器。展开后，选择器宽度跟着当前模型名称走，打开列表时拉宽到能显示最长的那一条；选择器和发送按钮底边对齐。展开后可在右上角拖动调整输入框高度。
- 新建会话页和每个会话各有自己的草稿，切走再切回来还在。
- 完成通知开出续跑轮时，输入框仍可打字：空着时按钮是「停止」，有字时是发送。发出的这句话先暂存，排在回执后面；续跑期间只能暂存一条。
- 用户气泡和助手回复下面有时间，会话页和解释栏各自计。同一天里这一页的第一条写成 `2026-09-07 13:55:44`，后面的只写 `13:55:44`，按本机时区。工具行、完成通知和报错不标。正在生成的回复，时间出现在第一段文字出来的时候。

## 权限卡与提问卡

两种卡片都叠在输入框上方，不铺一条底栏。

**权限卡**：标题「需要确认才能执行」，说明「允许后，这一轮剩下的写操作和命令不再逐条询问。停止会打断这一轮，但不会中止已经在后台运行的子代理。认得出的删盘根、格式化磁盘命令始终不执行。」按钮是「允许这一轮」「拒绝」「停止」。点「允许这一轮」后卡片收起，状态改为「执行工具…」。这次允许记在这一轮上；切到别的会话再回来，不会把已经确认过的同一张卡片再画出来。内置写操作和命令没有「只允许这一次」。MCP 调用是例外：标题换成「需要确认这次 MCP 调用」，按钮是「允许这一次」，这次点击不放行本轮剩下的写操作，见 [MCP](mcp.md)。一轮之内其余写操作仍按轮放行，见 [工具与权限](tools-and-permissions.md#分级与许可门)。

这段说明是在用户点「允许」之前讲清楚，这次点击放出去的是什么、收不回来的是什么。所以它不说「危险命令不会放行」，只说「认得出的」：名单认得出哪些、认不出哪些，见 [Shell 命令怎么分级](tools-and-permissions.md#shell-命令怎么分级) 的第 1 步。

**提问卡**：标题「需要你回答后才能继续」，下面是模型的问题，以及若干选项按钮，也可以在输入框里自己写回答。选项应当是用户自己的决定或事实，不是模型的下一步或让用户转述的提示。点选和手写都只作为这条 `ask_user` 的工具结果交还模型，对话里留在「提问」工具行中，不另画成用户气泡。

在 Windows 上，有卡片在等、而你没在看（窗口没有焦点、被最小化，或者卡片不在当前页）时，任务栏图标每 530 毫秒在两种颜色之间切换，直到卡片被处理。Electron 自带的 `setIcon` 只能换 16 像素的小图标，所以这里经 `koffi` 直接调 Win32 API 换上 256 像素的图标。这些系统库在确认是 Windows、第一次换图标时才加载，加载失败就退回 `setIcon`；其他系统上不加载。Windows 的应用程序控制策略若拦住 `koffi.node`，主进程不退出，任务栏继续用 `setIcon` 的 16 像素图标。

## 文件页

「日志」打开的是同一页黑底。页顶四个按钮切换记录：点中的是浅色，其余是深灰。打开会话不会去读这些文件；点「日志」才读当前这一页，`context` 留到点进那一页才读。`messages`、`trace`、`context` 三页按条折叠：标题是序号、角色或事件类型，再加一行摘要；展开后是这一条的 JSON，超过 1600 字的字符串截断。`meta` 页是整份 JSON。在 trace 页搜 `context_id`，就能在 context 页找到对应的请求。再点一次「日志」留在上次看的那一份，不回到对话。

## 页内搜索

`Ctrl+F` 只搜当前这一页，大小写不敏感，按原文包含来比，不用正则。高亮用 CSS Highlight API，不改写 Markdown 的 DOM；命中在折叠块里时会自动展开。查找框里 Enter 跳到下一处，Shift+Enter 跳到上一处。换页时沿用关键字，从该页第一处重新数。焦点在解释栏时，用的是解释栏自己的查找条。

比对按文本节点进行，所以被链接或加粗从中间切开的词搜不到。

## 任务面板

当前会话有任务时，输入框左侧、图片和视频按钮旁边出现「任务」和条数；清单为空就不显示。有进行中或被挡住的任务时，按钮用警告色。

点开后在输入卡片上方列出本会话的任务，只读：进行中、被挡住、待做，已完成的默认折起。被挡住的写明卡在哪一条；领取者是已经结束的子代理时，标成「领取者已结束」。确认卡出现时，任务面板在它上面。

## 问题轨

会话页有用户消息时，右侧出现问题轨，一条用户消息一个刻度。`ask_user` 的回答留在工具行里，不算一条用户消息，也不占刻度。平时只显示刻度，指针放上去才展开标题。标题截到 12 个字，悬停提示截到 80 个字；只有图片的记成「（图片）」。点某一条，平滑滚到这一轮在文档里的开头。贴顶的那一行只是标题，不能代替这次滚动；回答写到一半时再点同一条，会滚回该回答的开头。系统开启「减少动态效果」时改为直接跳到那里。

## 解释侧栏

界面上叫「答案解释」，文档里称解释侧栏。先在会话页或解释页选中一段文字，拖到展开着的解释栏里，或者右键选「解释」（会自动展开解释栏）。它用这段文字开一次简答：200 字以内，必要时联网搜索，最多列 3 条来源。从会话页拖出时，会带上选区所在那一轮的上下文；从解释页拖出的不带。

每个会话有自己的解释记录和展开状态，重启后还在。工作台的浏览器页也能用这一栏，记录另存，见 [我的工作台](#我的工作台)。同一时刻只跑一个解释，别的会话会显示「另一个会话的解释正在进行」；解释和主任务可以同时跑。还没有内容时，解释页写着「试试把文本拖到这里~」。

解释栏只用生文模型，不上传图片或视频。输入框缩小后只显示「简答」，没有模型选择器。解释在进行时，输入框无论有没有点过都收成一行，提示文字换成循环播放的阶段文字「思考中……」「执行工具……」，输入框上方不再另放一行阶段文字；这里没有 `ask_user`，所以一直收到这一轮结束，再恢复。点它、再展开的规则不变。展开后，左侧是只列出生文模型的选择器，发送按钮和选择器靠右；还没有生文模型时，点「未配置模型」打开模型页。这个选择器改的是配置里的 `currentExplainModelId`，不会改掉主对话正在用的那一条。解释栏标题行（机器人图标旁）有「只看用户问题」按钮，和会话页的一样：开着时只留用户气泡，点气泡展开或收起这一轮，发出新问题时这一轮自动展开。它按会话各记各的：切到别的会话，显示那个会话自己的状态，新会话默认是全部消息。只存在本次运行里，重启后回到默认。栏里还没有对话时隐藏。查找也跳过被藏起来的文字。

## 技能页

标题「技能」，显示「已安装(N)」和圆形加号的添加按钮。每张卡片可以开关、卸载，点卡片打开技能目录。卸载不需要确认。详见 [技能](skills.md)。

## 连接页

侧栏「连接」盖住主区，和技能、记忆、模型这几页互相替换。标题「连接」，显示「已配置(N)」和圆形加号的添加按钮。表单分本机命令和远程地址。每一行能看显示名、连接标识、状态、打码后的命令或地址，以及工具名和描述。可以开关、自动放行、重新连接、修改、移除。详见 [MCP](mcp.md)。

## 记忆页

侧栏「记忆」盖住主区，和连接、技能、模型这几页互相替换。它在这一行的第三位：连接、技能、记忆、模型。标题「记忆」。打开时和刚写下新记忆时重新读一遍，不监视目录。内容见 [记忆页](memory.md#记忆页)。

一轮正常结束、后台写入记忆之后，这条会话的对话末尾出现一行灰色的「已记住」，后面是名字。点名字打开这一页。每个名字后面有「撤销」，撤销这一次写入。正在生成新的一轮时，这一行补在上一轮的末尾，不插进正在流的文字里。它不写进会话记录，重新打开会话时不再出现；没打开过、或已经被挤出缓存的会话不画这一行。从一条记忆打开来源会话时，先关掉记忆页再打开那条会话。

## 模型页

侧栏「模型」盖住主区，和连接、技能、记忆这几页互相替换，排在这一行的最后。标题「模型」，显示「已配置(N)」和圆形加号的添加按钮。可以添加、复制、修改、移除多条模型：每条有显示名、类型（生文 / 生图 / 生视频 / 生音 / 网搜，缺省为生文）、Base URL、Model 和 API Key。选「网搜」时 Model 可以留空，API Key 必填，表单里会多一段说明。列表标题写成「名称 · 类型文案」，输入框旁的选择器写成「名称（类型文案）」。复制一条时会打开新记录的编辑表单，不会把当前选用改成副本。复制、修改、移除在鼠标移到该条时，或键盘焦点落在该条里时才出现。「使用」始终在最右侧；当前正在使用的那一条不显示「使用」，仍显示「当前」。密钥只存在本机用户目录，不会写入会话记录。其中一条对话模型是当前选用的；网搜模型另有自己的「当前」，两个「当前」同时显示、同时生效，点网搜模型的「使用」只换搜索用的那一条，不改对话模型。网搜模型不出现在输入框旁的选择器里，解释栏也不列它。主输入框展开后可以切换当前模型，下一轮主对话按这一条的类型走；解释侧栏用自己的生文模型选择器，见 [解释侧栏](#解释侧栏)。还没有配置时，输入框旁写「未配置模型」，点它打开这一页。旧的配置文件只有顶层的 Base URL、Model 和 API Key 时，打开后当作一条。详见 [配置](../README.md#配置)。

## 我的工作台

侧栏底部「我的工作台」打开一张盖住整个窗口的表，点 × 或按 Esc 关掉，回到原来的页面。左边是菜单，右边是当前这一项。菜单里有「常用文件夹」和「浏览器」。选中的那一项会记住：关掉工作台再打开，或重启应用后打开，都停在上次的那一项，不会回到第一项；只有第一次打开、或记住的那一项已经不存在时才是「常用文件夹」。

- **常用文件夹**：名单存在配置的 `favoriteFolders`。点一行在资源管理器里打开这个目录，不把它变成工作区。可以添加、移除、拖动改顺序。
- **浏览器**：右侧最上面一行，最左边是隐藏/显示菜单的按钮，后面是后退、前进、刷新和标签栏，下面是网页。第一次打开时有一个 DeepSeek 标签（`https://chat.deepseek.com/`），排在最前面，和其他标签一样可以关。点标签栏末尾的 + 新开一个空标签，这时标签栏下面才出现地址栏，光标已在里面，输入网址、回车打开，地址栏随即收起；标签最多 12 个，满了 + 不再生效。网页是独立的原生视图，盖在右侧那块区域上，不是界面里的一段 DOM，所以它不属于任何会话，也不进 `.agent` 的日志。
  - **隐藏菜单**：行首的按钮是一个箭头指向左边、从方框里出来的图标，点它收起左边的工作台菜单，网页占满整个窗口宽度；菜单收起后同一个位置上的按钮把图标转 180 度，点它把菜单找回来。菜单收起时，侧栏底部压在菜单上的「我的工作台」按钮也一起不见，关工作台用右上角的 × 或 Esc。这个选择会记住，下次打开还是这样。只有浏览器页能收起菜单：切到常用文件夹页时菜单一定在，因为要靠它切页面。
  - **DeepSeek 标签**：关掉它和关别的标签一样，关掉后不会自动再出现。找回它有两个办法：空标签中央有一个「打开 DeepSeek」按钮，只在 DeepSeek 标签关着时出现；或者在空标签的地址栏里输入 `deepseek.com` 下的地址，它会作为 DeepSeek 标签打开（带着它的登录），而不是一个普通标签，那个空标签随之消失。关掉 DeepSeek 不会退出登录。关掉最后一个标签时，会换成一个空标签，页面里始终有一个标签。标签已经满 12 个而 DeepSeek 关着时，没法再打开它，先关一个标签。重启后 DeepSeek 开着还是关着，也和上次一样。
  - **地址栏**：只在当前标签还是空的时候显示，也就是刚点完 +。切到别的标签、关掉这个空标签，或者标签有了网址，它都收起。所以已经打开了网页的标签里没有地址栏，想去别的网址就再点 +；想看当前网址，把鼠标放在标签上，标题提示里就是。输入完整的 `http://`、`https://` 地址，或只写域名（`example.com` 自动补 `https://`；`localhost`、IP 补 `http://`）。其他写法一律不打开：`javascript:`、`file:`、`data:`、`about:` 这类协议，没有点的单个词，带空格的文字。不认的输入框变红，不做搜索。DeepSeek 标签本身不离开它的站点：当前是 DeepSeek 标签时，输入的别的网址在新标签里打开。按 Esc 清掉这次输入并让输入框失焦，空标签的地址栏不会因此收起。
  - **标签**：标题跟着网页走，没有标题时显示域名，空标签叫「新标签页」。网页里 `window.open` 和 `target=_blank` 的链接开成新标签；DeepSeek 标签里指向 `deepseek.com` 之外的链接也开成新标签。空标签不占进程，输入第一个网址后才开始加载。后退、前进、刷新在标签栏左边，不随地址栏收起。
  - **关闭和重启**：关掉工作台，网页不会销毁，只是藏起来，所以再打开时每个标签都在原来的位置，滚动、没提交的输入、网页里的状态都还在，不重新加载。代价是它们占着的内存不会释放，网页里的脚本也继续跑。关闭时所有标签会被静音，再打开时恢复，所以后台的视频和音乐不会在你看不见的时候继续响；工作台关着时后台网页新开出来的标签，一开始也是静音的。重启应用后，标签按上次的网址恢复，包括 DeepSeek 标签当时停在的页面（只要它还在 `deepseek.com` 上）和上次停留的标签。恢复的只有网址和标题：标签先不加载，要等你切到它才开始加载，所以重启后打开工作台只会加载当前那一个标签，不会一次开出十几个页面；滚动位置、没提交的输入、网页里的状态都不会恢复。刚点完 + 还没输入网址的空标签不保存。DeepSeek 标签关着时，重启后它也关着，里面的页面也就不存了。网址存在 `~/.long-task-agent/browser-tabs.json`，是明文，带在网址里的参数（比如登录回调里的一次性参数）也会一起存下来。
  - **登录与权限**：DeepSeek 标签的登录状态单独存在 `persist:deepseek`，其余标签共用 `persist:browser`，两边互不可见，重启应用后登录都还在。网页不能申请摄像头、麦克风、定位和通知，只能写剪贴板。
  - **跟随与收起**：窗口缩放、页面缩放和工作台滑入滑出，网页都跟着；关掉工作台或切到别的菜单，网页收起，里面的页面继续运行，再打开时原样都在。
  - **视频全屏**：网页里点视频的全屏按钮（或网页自己要求全屏），窗口真的进入全屏，网页铺满整个屏幕，盖住界面和工作台菜单；按 Esc 或再点一次全屏按钮退出，窗口和网页回到原来的大小。全屏时焦点在网页里，Esc 归网页，所以它退出的是网页的全屏，不是关工作台。全屏中如果切了标签、新开了标签或关掉了工作台，或者关掉正在全屏的标签，全屏会先结束再切换，窗口不会留在全屏里。网页只获准用全屏，摄像头、麦克风、定位等权限仍然一律拒绝。
  - **解释**：解释栏和浏览器并排，是页面右侧从最顶到最底的一整列，标签栏只占左边那一列。页面上没有「解释所选」或「答案解释」之类的按钮，栏自己管展开和收起：展开时用栏里向右滑入的图标收起；收起后，标签栏最右边出现机器人图标，点它再展开。有两种方式把网页里的文字交给它：把选中的文字拖到展开着的解释栏里，和智能体页一样；或在网页里右键选「解释所选文字」，栏会自动展开。右键菜单只有「解释所选文字」和「复制」，没选中文字时两项都是灰的。拖进来的只有纯文本，在输入框里松手是往输入框里放字，不会提问；拖文件进来不会提问。这一栏就是智能体页的那个解释栏，换了位置，所以模型选择、查找、样式都一样，离开浏览器页它回到原处。浏览器里的解释另存一份，放在 `~/.long-task-agent/browser-explain/`，不属于任何会话，也不进工作区；它和智能体页的解释不共用记录。拖入或右键的文字最多 4000 字，超出的部分直接截掉。解释栏同一时刻全局只跑一个，所以另一个会话的解释在跑时，这里会显示「另一个会话的解释正在进行」。
  - **Esc**：焦点在网页里时，键盘归网页，Esc 到不了界面，这时用右上角的 × 关闭工作台。点一下左侧菜单，焦点回到界面，Esc 又可用。
  - **弹窗登录的限制**：`window.open` 开出的新标签没有 `window.opener`，靠它回传结果的第三方登录（部分 Google、微软账号登录）完成不了。用手机号或邮箱登录没有这个问题。

## 图片与视频

主输入框可以选择或粘贴 PNG、JPEG、WebP、GIF，每条消息最多 4 张；也可以选一个 MP4、WebM 或 QuickTime 视频，最大 20 MiB。不支持把文件拖进来。图片上传前长边缩到 1600 像素；PNG 保持 PNG，其余转成 JPEG，GIF 只留第一帧。编码结果超过 900,000 字节时再压成质量 0.8 的 JPEG，PNG 也不例外。视频按原文件保存，对话里用内置的播放控件播放，没有另嵌播放器。解释栏不提供上传图片或视频的按钮。

生图得到的图出现在助手气泡里，和上传的图一样可以点开。查看器是应用自己提供的：可以放大、缩小、复位，滚轮对着指针缩放，放大后按住拖动平移；左右方向键或「上一张」「下一张」只在同一条消息的这组图里切换。点遮罩、点关闭或按 Esc 关掉。正文里的 Markdown 图片不会打开这个查看器。

用户气泡贴在对话顶部并折起时，如果气泡里还有文字，图片和视频会暂时收起；这条不再贴顶，或已经滚回顶部时，会再显示出来。

## 快捷键与其他

- Enter 发送，Shift+Enter 换行。
- Esc 关掉最近的那个东西：查看图片、工作台、查找条（主区或解释栏的）、任务面板，都没开时才停止正在看的这一轮。查看器开着时，Esc 只关掉它，不会停止这一轮。工作台盖住整个窗口，所以它比查找条优先。改名框、技能菜单、右键菜单、记忆页的编辑框用掉的 Esc 不再往下传，编辑框里按 Esc 只取消这次编辑；输入法正在组字时，Esc 只取消组字。这套顺序在 `src/renderer/escapeKey.ts`，有单独的测试脚本。
- 右键菜单有「复制」和「解释」。没选中文字时，「复制」拷贝整页内容。
- 被停止或没有得到回答的问题下面有「重新问」，只有图片或视频、没有文字的也有。点下去会把原来那句和原来的图片、视频再发一次，输入框里正在写的字和已经选上的附件留在原地。两条消息用会话里的同一个图片或视频文件。
- 后台完成的回执画成「后台完成」卡片，可以「展开↓」「收起↑」。
- 主区和解释栏里的网址用浏览器打开。本地路径是目录就打开这个目录，是文件就在资源管理器里选中它，不直接运行；不存在的路径会去掉链接。
