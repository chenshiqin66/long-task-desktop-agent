# 界面行为

窗口分三栏：左边是工作区和会话列表，中间是主区，右边是可以收起的「答案解释」。主区一次只显示一页：会话页、四个文件页之一，或者技能页。

几条贯穿全局的规则：实时状态只出现在它自己的会话页上；输入框和草稿跟着页面走；切到别的会话查看，包括别的工作区的会话，不会打断正在执行的那一轮。重新加载页面会取消当时正在执行的轮次。

## 布局

- 会话页的标签显示会话标题，缺省是「会话」。打开会话后，旁边出现四个文件页：「meta」「messages (N)」「trace (N)」「context (N)」，各占整页。新建会话页上不显示这排标签。
- 输入框是浮在主区底部的白卡片，只在会话页出现，不占一条横贯的底栏。对话区底部留出与卡片等高的空白，最后一行不会被挡住。
- 右侧「答案解释」用「<-解释」打开，「收起->」关闭；打开时分走主区的一部分宽度。

## 工作区与会话

- 侧栏可以记多个工作区，点 + 是增加，不会换掉已有的那一条。后添加的工作区排在上面。工作区里的会话按最近一次写入消息的时间排，刚说过话的在上面。别的会话正在执行时也可以增加。
- 点工作区名字或旁边的箭头，只展开或折叠它的会话，不换掉右侧正在看的页面。展开和折叠记在本机配置里，重启后保持。
- 工作区的「⋯」菜单有「打开文件夹」「重命名」「从列表中移除」。只有没有会话的工作区才能移除。重命名只改侧栏显示，不改目录名。
- 会话的「⋯」菜单可以就地改名和删除，删除前要确认。菜单挂在 `document.body` 上，避免被侧栏的滚动容器裁掉。
- 看过的会话把对话节点留在内存里，最多 8 份；正在执行或等你确认的那一份不会被挤掉。切回来时直接挂回这份节点，不读盘，所以你不在时到达的文字和工具行当时就画进它。删除会话时这份缓存一起丢掉；这一轮会被取消，后台子代理也会先停掉，见 [子代理、任务清单与完成通知](subagents-and-tasks.md#停止)。

## 发送、停止与并发限制

同时执行最多 5 个 runtime。上限和输入框的分工见 [路线图](roadmap.md#不同会话同时执行)。

- 正在执行的那一页，发送按钮变成「停止」；点了之后是灰色的「正在停止」，直到这一轮真正结束。等你回答问题时，按钮是「回答」。停止只取消这一条。
- 别的会话正在执行时，当前页照常打字、照常发送。阶段提示留在它自己那一页，不会带过来。
- 左侧每个还占着名额的会话标题前有一枚转圈，父轮次结束后，只要后台子代理还没结束，圈就继续转。工作区被折叠、里面却有这样的会话时，转圈改标在工作区名字前。停在权限确认或「等你回答」、而你正看着别处时，转圈换成不转动的等待标记。这一轮已经结束时，输入框可以再发；停止只取消还在这一轮里的工作，不会取消已经交给后台的子代理。
- 新建会话页和每个会话各有自己的草稿，切走再切回来还在。
- 完成通知开出续跑轮时，输入框仍可打字：空着时按钮是「停止」，有字时是发送。发出的这句话先暂存，排在回执后面；续跑期间只能暂存一条。

## 权限卡与提问卡

两种卡片都叠在输入框上方，不铺一条底栏。

**权限卡**：标题「需要确认才能执行」，说明「允许后，这一轮剩下的写操作和命令不再逐条询问。停止会打断这一轮，但不会中止已经在后台运行的子代理。认得出的删盘根、格式化磁盘命令始终不执行。」按钮是「允许这一轮」「拒绝」「停止」。没有「只允许这一次」：一轮之内逐条确认被刻意省掉了，见 [工具与权限](tools-and-permissions.md#分级与许可门)。

这段说明是在用户点「允许」之前讲清楚，这次点击放出去的是什么、收不回来的是什么。所以它不说「危险命令不会放行」，只说「认得出的」：名单认得出哪些、认不出哪些，见 [Shell 命令怎么分级](tools-and-permissions.md#shell-命令怎么分级) 的第 1 步。

**提问卡**：标题「需要你回答后才能继续」，下面是模型的问题，以及若干选项按钮，也可以在输入框里自己写回答。选项应当是用户自己的决定或事实，不是模型的下一步或让用户转述的提示。点选和手写都只作为这条 `ask_user` 的工具结果交还模型，对话里留在「提问」工具行中，不另画成用户气泡。

在 Windows 上，有卡片在等、而你没在看（窗口没有焦点、被最小化，或者卡片不在当前页）时，任务栏图标每 530 毫秒在两种颜色之间切换，直到卡片被处理。Electron 自带的 `setIcon` 只能换 16 像素的小图标，所以这里经 `koffi` 直接调 Win32 API 换上 256 像素的图标。这些系统库在确认是 Windows、第一次换图标时才加载，加载失败就退回 `setIcon`；其他系统上不加载。

## 文件页

`messages`、`trace`、`context` 三页按条折叠：标题是序号、角色或事件类型，再加一行摘要；展开后是这一条的 JSON，超过 1600 字的字符串截断。`meta` 页是整份 JSON。在 trace 页搜 `context_id`，就能在 context 页找到对应的请求。

## 页内搜索

`Ctrl+F` 只搜当前这一页，大小写不敏感，按原文包含来比，不用正则。高亮用 CSS Highlight API，不改写 Markdown 的 DOM；命中在折叠块里时会自动展开。查找框里 Enter 跳到下一处，Shift+Enter 跳到上一处。换页时沿用关键字，从该页第一处重新数。焦点在解释栏时，用的是解释栏自己的查找条。

比对按文本节点进行，所以被链接或加粗从中间切开的词搜不到。

## 任务面板

当前会话有任务时，输入框左侧、图片按钮旁边出现「任务」和条数；清单为空就不显示。有进行中或被挡住的任务时，按钮用警告色。

点开后在输入卡片上方列出本会话的任务，只读：进行中、被挡住、待做，已完成的默认折起。被挡住的写明卡在哪一条；领取者是已经结束的子代理时，标成「领取者已结束」。确认卡出现时，任务面板在它上面。

## 问题轨

会话页有用户消息时，右侧出现问题轨，一条用户消息一个刻度。`ask_user` 的回答留在工具行里，不算一条用户消息，也不占刻度。平时只显示刻度，指针放上去才展开标题。标题截到 12 个字，悬停提示截到 80 个字；只有图片的记成「（图片）」。点某一条，滚到那条消息。

## 解释侧栏

界面上叫「答案解释」，文档里称解释侧栏。先在会话页或解释页选中一段文字，拖到展开着的解释栏里，或者右键选「解释」（会自动展开解释栏）。它用这段文字开一次简答：200 字以内，必要时联网搜索，最多列 3 条来源。从会话页拖出时，会带上选区所在那一轮的上下文；从解释页拖出的不带。

每个会话有自己的解释记录和展开状态，重启后还在。同一时刻只跑一个解释，别的会话会显示「另一个会话的解释正在进行」；解释和主任务可以同时跑。还没有内容时，解释页写着「试试把文本拖到这里~」。

## 技能页

标题「技能」，显示「已安装(N)」和「+ 添加技能」。每张卡片可以开关、卸载，点卡片打开技能目录。卸载不需要确认。详见 [技能](skills.md)。

## 图片

输入框可以选择或粘贴 PNG、JPEG、WebP、GIF，每条消息最多 4 张，不支持把文件拖进来。上传前长边缩到 1600 像素；PNG 保持 PNG，其余转成 JPEG，GIF 只留第一帧。编码结果超过 900,000 字节时再压成质量 0.8 的 JPEG，PNG 也不例外。解释栏只做缩放和转码这一步。

## 快捷键与其他

- Enter 发送，Shift+Enter 换行。
- Esc 关掉最近的那个东西：查找条（主区或解释栏的）、任务面板，都没开时才停止正在看的这一轮。改名框、技能菜单、右键菜单用掉的 Esc 不再往下传；配置对话框开着时 Esc 只关对话框；输入法正在组字时，Esc 只取消组字。这套顺序在 `src/renderer/escapeKey.ts`，有单独的测试脚本。
- 右键菜单有「复制」和「解释」。没选中文字时，「复制」拷贝整页内容。
- 被停止或没有得到回答的问题下面有「重新问」。
- 后台完成的回执画成「后台完成」卡片，可以「展开↓」「收起↑」。
- 网址用浏览器打开。本地路径是目录就打开这个目录，是文件就在资源管理器里选中它，不直接运行；不存在的路径会去掉链接。
