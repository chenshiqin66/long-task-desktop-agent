# MCP

MCP server 是一份会变的工具表，不是技能。技能是 `SKILL.md` 和脚本，装上就能读。MCP server 是一个子进程，或一个远程端点，握手之后才把工具交给模型。配置在用户目录，所有工作区共用一份连接。工具只进入主会话：子代理和解释侧栏的工具表里没有它们。

内置工具的副作用可以在本地分级。对方提供的工具不行：说明文字由 server 填写，标注成只读也不采用。所以这些工具不走「允许这一轮」，也不放进不经过确认门的子代理。

## 一份连接池，按轮快照

`McpPool` 在主进程里创建一份，传给每一个 `AgentRuntime`。最多五个会话共用这一份，不为每个 runtime 再开一套客户端。逻辑在 `@agent/core`，Electron 只做 IPC、连接页，以及退出时关掉子进程。

每一轮开始时调用 `currentTools()`，把当时已连接的工具定义拍进这次循环。这一轮中途添加、断开或失败，模型看见的表不变，下一轮才变。真正发出的调用走当时的连接：定义是旧的，连接可以已经换过。正在进行的握手带一个代数，重连或移除会把代数加一，过期的结果丢掉。

配置写入串行。退出时先拒绝新的退出请求，等连接池关掉 stdio 子进程再退出应用。

## 两种传输

只做这两种。不做 OAuth，不做资源和提示词，这个应用自己也不对外当 MCP server。资源和提示词不在这条工具路径上；OAuth 是另一套登录产品。

**本机命令（stdio）。** 命令、参数、环境变量、可选工作目录。进程由 SDK 以 `shell: false` 拉起。环境是 SDK 的默认环境（`PATH` 等）加上你填的变量；Windows 上再补 `PATHEXT` 和 `COMSPEC`。不继承父进程里的其他密钥。命令名是 `npx`、`npm`、`pnpm`、`yarn` 时，实际启动的是对应的 `.cmd`。关掉时用 `taskkill /T /F` 结束整棵进程树。

**远程地址（Streamable HTTP）。** 一个 `http` 或 `https` URL。重定向只跟随同一来源，避免查询串里的密钥被 302 带到别的主机。

## 名字

显示名和连接标识是两件事。显示名给人看，最长 40 个字符，可以用中文，不参与工具名。空着就用连接标识。

连接标识是 `^[a-z0-9]+(?:-[a-z0-9]+)*$`，长度 1 到 32。它从远程地址的主机名，或本机命令的包名、项目目录生成：去掉开头的 `www.` 和 `mcp.`，取第一段标签，所以 `https://mcp.example.com/mcp` 得到 `example`；`npx -y @scope/notes-mcp` 得到 `notes-mcp`。IPv4 保留每一段，写成 `127-0-0-1`。同一标识已被占用时加上 `-2`、`-3`。地址或命令还提不出标识时才手填。保存后标识不再改，改地址也不会改名。只改显示名不重新握手。

模型看见的名字是 `mcp__<server>__<tool>`。远程名字里不能放进函数名的字符换成下划线。拼出来超过 64 个字符时，尾部收成哈希，这样能放进 OpenAI 兼容接口的函数名上限。一个 server 最多注册 64 个工具，再多的列表被截断，连接页会说明只注册了前 64 个。内置工具和 MCP 工具撞名时，内置的留下。说明收成一行，截到 800 字，前面加 `[MCP 服务器名]`。参数的 JSON Schema 原样放进 `tools` 数组，不截断，也不写入 system 正文。调用结果先打码，再按 `maxToolOutputChars` 截断；发出去的副本里，不再属于最后一批、且超过 500 字的结果换成一行短桩。

## 确认

没开自动放行时，每次调用都要确认。`classifyToolCall` 对 `mcp__` 前缀给出 `write`，并带上 `grant: "once"`。卡片标题是「需要确认这次 MCP 调用」，按钮是「允许这一次」。这次允许不把 `turnWritesAllowed` 设上，所以盖不住本轮剩下的写操作和命令，下一次 MCP 调用也会再问。先点过内置工具的「允许这一轮」，MCP 调用仍会再问。

自动放行把这个 server 已连上的工具改成 `read`，只跳过它自己的卡片。写文件、命令和其他 server 仍按原规则。

子代理直接执行工具，不经过 `classifyToolCall`。因此 `toolsForSubagent` 的名单里没有 `mcp__`，提示词也要求父会话自己调用。任务清单把步骤派出去之后，调查交给 `explore`，写文件交给 `worker`；shell 和任何一个 `mcp__` 工具留在父会话：父会话领取，然后自己调用。查询结果要给子代理用时，写进任务正文。

解释侧栏仍只有 `web_search`。

## 配置与密钥

```text
~/.long-task-agent/mcp-servers.json
```

和 `config.json` 分开，避免模型配置的读写把 server 密钥卷进去。写入先落到临时文件再改名，文件模式 `0600`，目录 `0700`。文件不存在时当作没有 server。不是合法 JSON，或缺少 `servers` 数组时，不改这个文件，连接页说明原因，这时不能再添加或修改；没有文件监视，改好后要重启。某一条读不出来时，其余能读的照常连接，修改同样先被挡住。

密钥留在这个文件里：stdio 的环境变量，或 URL 的查询参数。连接页、报错和交还给模型的工具结果会打码 `key`、`api_key`、`apikey`、`token`、`access_token`、`secret`、`password`，也会把配置里已知的、长度不少于 6 的密钥字符串换成 `***`。打码在截断之前，避免密钥被截成两段后漏出一半。模型看不到地址本身。

工具结果超过 `maxToolOutputChars` 时截断。server 报错变成 `is_error` 的工具结果，这一轮继续。

## 连接页

侧栏「连接」盖住主区，和技能页互相替换。一行一条连接：显示名、连接标识、状态、打码后的命令或地址、工具名和 server 自己的描述。可以开关、自动放行、重新连接、修改、移除。改命令、地址或环境变量会重新握手。界面行为见 [界面行为](ui-behavior.md)。
